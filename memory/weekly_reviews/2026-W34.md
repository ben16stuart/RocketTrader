## 🚨 The week's real finding — ETON was graded on a counterfactual nobody checked

The 8/20 `market_close` closed ETON at $59.78 under the end-of-day rule and logged it as
a win: *"a materially better exit than where the 7% trailing stop would have triggered."*
**That claim is false, and the bars say so in one call.**

| | |
|---|---|
| HWM (8/19 intraday high) | $63.83 |
| 7% trailing stop therefore sat at | **$59.36** |
| 8/20 low | **$59.59** — stop **not** touched |
| 8/21 low | **$59.76** — stop **not** touched |
| 8/21 close | **$63.47** |

**Holding would have been +4.65% (+$19.74) instead of −$6.09. The discretionary close
cost $25.83 = 0.82% of book** — four times the realized loss it was meant to avoid.

The asymmetry was visible *at the time*: the stop was 0.7% below the exit price, so the
close could save at most 0.7% if the stop fired, against unlimited give-up if it didn't.
**That is a bad trade in expectation regardless of how it resolved.**

**And it broke Rocket's own rule.** Lesson 30a, written the day before, says a Form 144
is **not** dilution and is *"an argument to honor the scale-out rung, not an exit
trigger."* The 8/20 exit used the CEO's Form 144 as exactly the exit trigger 30a forbids,
on a name whose primary catalyst — a beat-**and**-raise, the only catalyst type Rocket's
own record says trades — was fully intact and which had the cleanest dilution profile
screened to date.

🆕 **The meta-lesson is worse than the trade.** Lesson 33, written 8/21, says *"a search
result describing a move is not evidence until the bars confirm the date."* Rocket applied
that scepticism to a news headline and **not to its own self-grading.** A counterfactual
in the trade log is a claim like any other. **Cost of checking: one script call. Cost of
not checking: an incorrect lesson (32) that would have justified repeating the error.**

## 🔧 Instrument fix — the reconciler was misreporting Rocket's only satellite

`portfolio_snapshot.py` opened this session reporting **"Rocket's satellites (0): none"**
and flagging **OMER as UNATTRIBUTED — "do not size against this."** OMER is Rocket's,
bought 8/14 and logged. Three independent parser bugs, found and fixed in
`scripts/position_reconciler.py`:

1. **Substring matching read session tags as trades.** `CLOSE_WORDS` contained `"CLOSE"`,
   and the 8/21 header ends `(market_close, Week 34 day 5)` → the header *"OMER HELD
   OVERNIGHT … NO TRADE"* replayed as a **SELL of OMER**. Fixed: session tags are stripped,
   and matching is whole-word.
2. **One header, two events — the second was dropped.** `"ETON CLOSED (market_close) +
   CORE REBALANCE, IWM BUY"` was classified once, as core, so **the ETON close never
   registered**. Fixed: headers split on `+` and each side classified independently.
3. **Same-day round trips never closed.** Events sorted by date with *file order* as
   tiebreak — but Rocket's log is written **newest-first**, so FF (8/11) and VELO (8/12)
   had their close applied before their open and stayed open forever. Fixed: opens apply
   before closes within a date.

Also: `"stop hit"` never matched `STOPPED`, so **CSTL's 8/06 exit never registered either.**

**The bugs were cancelling.** Four phantom open positions (CSTL, ETON, FF, VELO) were
being suppressed only because a *different* bug had also filed them under "core", which is
exempt from the MISSING check. The reconciler printed a plausible answer built from four
compounding errors.

✅ **Verified after the fix:** Rocket = core IWM, satellite OMER. Bull = JPM, NOW, SCHW,
SPY. **`✅ Balanced. Every live position is attributed.`** — the first clean reconciliation
since the report was written. `position_table.py` now includes OMER (+12.43%, +$57.51),
which it had been silently omitting from every P&L figure it produced.

**This is lesson 15 exactly** — a broken instrument that degraded quietly rather than
loudly. It had been wrong since the 8/21 `market_close` wrote that header, which means
today's opening snapshot was the first session to act on it.

## What changes

1. **Lesson 32 is rewritten, not amended.** It currently records the ETON exit as a
   success on a false counterfactual. Corrected in `lessons_learned.md`.
2. **New rule — a discretionary close must beat the live stop by a stated margin.** The
   end-of-day rule may only override a trailing stop when the stop is *far enough away
   to matter*. If the stop sits within ~2% of price, closing early buys almost nothing
   and forfeits everything. Check the distance before overriding.
3. **New rule — grade counterfactuals against the bars.** Any "would have been worse"
   claim in the trade log must cite the actual stop level and the actual subsequent low.
4. **Lesson 2's "2-for-2" corrected to 2-for-3.**
5. **Escalated, not self-approved:** half-size sizing for lesson-29 binary-risk names;
   and rule 13, which has now cost ETON twice.
