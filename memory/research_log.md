# 🚨 THE FINDING: lesson 48 is **NOT 8-for-8. Measured correctly it is 5-for-11**, and the statistic it was built on is the wrong one

For eight sessions this file has killed names by comparing **daily range ÷ 7% trail** and
concluding "Rocket could not have HELD a single one." KMTS's settled catalyst bar made that
claim testable, and it fails.

**A trailing stop does not key on daily range. It keys on retracement from the running
high-water mark.** Those are the same number only on a round-trip bar. On a one-way trend bar
they are wildly different — and a one-way trend bar is *exactly* what rule 4 selects for.

**KMTS 9/15, measured on 78 five-minute bars:** range **15.40% = 2.20× the trail** → the old
diagnostic says un-holdable. **Actual max drawdown from the running high: 6.18%**, and it
occurred in the **9:30 bar**, before any high-water mark existed. **A 7% trail entered at the
open was never threatened and would have ridden the name to +15.49% — rung 1, exactly.**
